# Security Policy

## Supported versions

Security fixes are provided for the latest published Conduit release. Upgrade
to the latest release before reporting a problem when practical.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability.

Use GitHub's
[private vulnerability reporting](https://github.com/parm2006/Conduit/security/advisories/new)
to contact the maintainer. Include:

- The affected Conduit version and installation method.
- The affected Windows versions and server/client roles.
- Steps to reproduce the issue or a minimal proof of concept.
- The security impact and any conditions required to trigger it.
- Suggested mitigations, if known.

Do not include real passwords, private keys, certificates, pairing secrets,
personal data, or sensitive clipboard contents. Use synthetic test data.

The maintainer will acknowledge a report as soon as practical, normally within
seven days, and will coordinate validation, remediation, and disclosure with
the reporter. Please allow time for a fix before publishing details.

For ordinary bugs that do not create a security risk, use the public bug report
form instead.
