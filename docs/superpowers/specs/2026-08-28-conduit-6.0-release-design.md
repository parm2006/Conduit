# Conduit 6.0 Release Design

**Status:** Approved

**Date:** 2026-08-28

**Planned against:** `9a40497`

## Release identity

This release is Conduit `6.0`. The application title, installer display
version, artifact names, source link, release notes, and Git tag use `6.0` and
`v6.0`. Windows requires a four-part numeric resource version, so executable
and installer file metadata use `6.0.0.0`; this does not change the public
product version.

## Integration

Reconcile `origin/main` into `multimonitor` before release. The sole
main-only commit contains the initial topology design; retain the expanded
design from `multimonitor`. After verification, fast-forward `main` to the
release-preparation commit and push both branches without rewriting history.

## Artifacts

Create an official clean tagged build through `scripts/build_release.ps1`.
The release set contains:

- `Conduit-v6.0.exe`
- `Conduit-v6.0-Setup.exe`
- `Conduit-v6.0-source.zip`
- `THIRD_PARTY_NOTICES.txt`
- `RELEASE_MANIFEST.txt`
- `SHA256SUMS.txt`

Build from a clean detached `v6.0` worktree so unrelated local files remain
untouched. Do not publish a GitHub Release unless separately requested.

## Verification

Update the canonical metadata test before production metadata. Run its red and
green phases, then compileall, the complete unit suite, and `diff --check`.
After tagging, run the official release script without its development bypass
and verify every artifact and checksum it reports.
